# Fuera de alcance

Decisiones conscientes para no diluir HubForge.

## Fuera del MVP

- Chat propio (canales o DMs). HubForge se integrará con Discord en el futuro; no lo sustituye.
- Videollamadas o voz.
- Almacenamiento de archivos creativos (arte, audio, vídeo).
- Sustitución completa de GitHub Projects o Issues.
- Aplicación móvil nativa.
- IA generativa como requisito central del producto.
- Facturación real / Stripe.
- Analítica empresarial avanzada.
- Integraciones múltiples además de GitHub (en el MVP).
- Gamificación.
- Editor documental completo.
- Tablero Kanban como propuesta principal de marketing (puede existir como vista secundaria de Trabajo).

## Nunca es el objetivo de HubForge

- Ser otro gestor de proyectos genérico.
- Competir con Discord como mensajería del equipo.
- Centralizar “todo el trabajo del equipo en un único lugar” sin mecanismo claro.
- Servir a grandes corporaciones que buscan reemplazar Jira.
- Funcionar para equipos que no usan GitHub.

## Chat y datos existentes

El schema y el código de chat pueden permanecer en el repositorio durante la transición. Se retiran de navegación, command palette, landing y documentación. No se ejecutan migraciones destructivas ni borrado de tablas sin autorización explícita. Ver ADR 0006.
