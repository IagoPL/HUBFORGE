# Roadmap

HubForge está **en desarrollo**. Este roadmap describe intención, no fechas de lanzamiento ni promesas de producción.

## Ahora (reposicionamiento en curso)

- Documentación de producto alineada (capa operativa sobre GitHub).
- Navegación Briefing / Atención / Trabajo / Dependencias / Equipo / GitHub / Ajustes.
- Motor de señales determinista y briefing fiel a la última visita.
- Cola de atención, impacto de dependencias, capacidad operativa.
- Modo demostración indie.
- Soft-retire del chat en superficies visibles.
- Pruebas de señales, demo y flujos críticos.

## Después (cuando el núcleo operativo esté estable)

- Integración con Discord (notificaciones / puente), no chat propio.
- Inferencias adicionales documentadas (siempre etiquetadas).
- Mejoras de onboarding de la GitHub App en entornos reales.
- Pulido de accesibilidad y densidad en sesiones largas.

## Más adelante (explícitamente no comprometido)

- IA de apoyo a triage (opcional, no núcleo).
- Analítica ligera de avance (sin vanity enterprise).
- PWA / avisos push.
- Facturación si el producto deja de ser gratuito.

## No roadmap

Sustituir Jira, Discord, GitHub Projects o el almacenamiento creativo del estudio.
